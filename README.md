## دربارهٔ فایل‌ها

نوت‌بوک‌ها و کدها از آرشیو محلی درس‌ها تهیه شده‌اند. خروجی‌های نوت‌بوک، شناسهٔ دانشجویی و توکن‌های دسترسی از نسخهٔ انتشار حذف شده‌اند. کدها هنگام آرشیوسازی دوباره اجرا نشده‌اند؛ فایل‌های وابسته به داده یا مدل، پیش از اجرا به آماده‌سازی محیط نیاز دارند. نسخهٔ Python استخراج‌شده از نوت‌بوک ممکن است دستورهای IPython داشته باشد.

قالب تمرین و صورت پروژه با برچسب جدا مشخص‌اند و پروژهٔ تکمیل‌شده محسوب نمی‌شوند. یادداشت‌های مطالعه نیز پژوهش مستقل معرفی نمی‌شوند. پوشهٔ notebooks استاد به نام کار شخصی بازنشر نشده است. ارجاع منابع و حقوق مؤلفان در [THIRD_PARTY.md](THIRD_PARTY.md) آمده است.

داده‌های خام، وزن مدل‌ها، فایل‌های نمره و تصحیح دانشجویان، کتاب‌ها و کارهای خصوصی پایان‌نامه در این مخزن قرار ندارند.
